# Settlbox source organization

- app: Next.js routes and server endpoints.
- presentation: business screens, interface components and application adapters.
- components and contexts: shared interface and live Arc wallet support.
- services: persistence, authentication, business logic and Arc integration.
- types: shared domain definitions.
- scripts and tests: development operations and verification.
- public: brand, network, token and interface assets.

A file being present or typechecked does not establish that a user-facing route executes it.
