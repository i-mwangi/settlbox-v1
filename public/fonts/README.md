# Locally hosted UI fonts

Inter is the interface typeface (normal weights 400–700). Geist Mono supplies monospace text. Nanum Pen Script and Anton supply the existing decorative styles.

These fonts come from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/geistmono
- https://github.com/google/fonts/tree/main/ofl/nanumpenscript
- https://github.com/google/fonts/tree/main/ofl/anton

Each corresponding `*-OFL.txt` file contains its license and copyright notices. The application serves the font files locally through Next.js rather than contacting Google Fonts during builds or page loads.

Existing Repetition Scrolling, DFVN and Complain assets are retained unchanged.
